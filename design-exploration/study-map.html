Study map: four directions

Each option is drawn from the same real structure as the app: courses, upcoming assignments (sized by estimated time), their study blocks, and the "Overdue" and "Needs time" flags. The data is the app's sample semester.

These are static mockups. In the app the map stays springy and draggable, with hover highlighting, click-to-open and the same filters. Hover a node here to see the tooltip style.

All four keep the map's behavior: filters, hover focus, click to open an assignment or its week, and drag to rearrange. They differ in what the map tells you at a glance, and in how much of its drawing code changes.

My pick: A, with C's rings

A's mint pills are exactly what you described and make courses unmistakable. Adding C's coverage rings to the assignment dots gives the map a job the calendar can't do as well: showing at a glance which work is ready and which still needs time. Study-block dots can then be hidden by default, which removes most of the clutter.

The app already calculates coverage for the "Needs more study time" list, so the rings reuse existing logic.

Worth knowing

  • Mint means "yours" elsewhere in the app (study blocks, today). Mint course pills stretch that rule a little. If that bothers you, C's neutral pills keep mint for study time only.
  • Long course names like "CS 210 Intro to Programming" make wide pills. The pills shorten them to the course code ("CS 210"), with the full name on hover.
  • B carries the most text, so it gets crowded with 6+ courses. The others scale better.
  • D changes the layout itself. Distance from the course means time, so dragging a node would fight that rule.
