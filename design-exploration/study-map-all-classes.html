The panel on the right is the way in: pick a class, then a test, and the map glides over to the weeks that test covers. You can still zoom out and drag around freely, and Show all brings everything back into view.

A. Free-floating

All classes live in one springy map and push each other apart.

The closest to how the map feels now. Drag a class pill and its whole branch follows. Where classes end up shifts a little each visit.

  • Good: organic and playful; the whole map moves as one thing.
  • Trade-off: Math isn't always in the same spot, so finding it takes a glance.
  • Trade-off: branches can drift into each other with 5–6 classes.

B. Islands Recommended

Each class has its own fixed spot; only its weeks and work are springy.

Classes sit side by side like islands, in the same order every time. Inside an island everything still drags and springs back, exactly like the map you just tried.

  • Good: Math is always in the same place, so the glide always goes the same way and you learn the map.
  • Good: branches never overlap, even with 5–6 classes.
  • Trade-off: a bit tidier and less free-form than A.
